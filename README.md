Student Expense Tracker

1. Introduction

The Student Expense Tracker is a web-based application that helps students manage and track their daily expenses. It allows students to record their income and expenses, monitor spending habits, and manage their budget effectively.

2. Objectives

- To track daily expenses.
- To manage monthly budgets.
- To record income and spending.
- To reduce unnecessary expenses.
- To improve saving habits among students.

3. Features

- User Registration and Login
- Add Daily Expenses
- Add Income Details
- View Expense History
- Categorize Expenses
- Calculate Total Expenses
- Monthly Budget Management
- Expense Reports and Summary

4. Technologies Used

Frontend:

- HTML
- CSS
- JavaScript
- React.js

Backend:

- Node.js
- Express.js

Database:

- MongoDB

Tools:

- Visual Studio Code
- GitHub

5. How to Run the Project

1. Download or clone the repository.

2. Open the project in VS Code.

3. Install dependencies:
   
   "npm install"

4. Run the application:
   
   "npm run dev"

5. Open the local URL displayed in the terminal.

6. Future Enhancements

- Monthly expense charts.
- Budget alerts and notifications.
- Download expense reports.
- Mobile-friendly design.
- Savings recommendations.

7. Conclusion

The Student Expense Tracker helps students manage their money efficiently by tracking daily expenses and income. It encourages financial discipline and better budgeting habits.
